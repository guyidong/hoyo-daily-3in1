# 三游戏每日一条龙（原神 / 崩铁 / 绝区零）

> 一个**调度层**：把社区三个成熟工具串成"开机即跑、跑完自动收工"的每日流水线，并提供一个**本地网页配置面板**。

**本项目不重复造轮子、不打包、不修改任何上游代码**。游戏内的所有识别与操作，全部由下列上游项目完成：

> ⚠️ **成熟度说明（务必先读）**：本项目源于**个人自用**的三游戏调度需求，配置面板只覆盖**最常用的字段**（开关/游戏路径/目标任务/次数/定时）。三个上游工具各自都有**大量更细的配置**（队伍、装备策略、战斗脚本、体力分配、副本轮次、通知等等）——**这些请直接在各工具的图形界面里调整**，它们与调度层读的是同一份配置文件，不会冲突。欢迎按需 PR 扩展面板字段。

|---|---|---|

## ✨ 本项目做了什么（调度层的价值）

1. **一键配置网页**（`web_config.py`）：三个游戏开关 / 游戏路径 / 目标任务 / 次数 / 定时时间，浏览器里点几下即可
2. **每日定时全自动**：Windows 计划任务（每天 7:30，最高权限）→ 依次跑 原神 → 崩铁 → 绝区零
3. **零 UAC 无人值守**：任务本身最高权限运行，子进程直接继承 → 全程不弹任何确认框
4. **自动切换窗口 / 自动还原全屏**：跑之前切 1920×1080 窗口化，跑完**自动恢复你自己的全屏分辨率**
5. **错过补跑 + 电池也跑 + 防重复**：7:30 时若关机/没登录，开机登录后自动补跑；单实例锁避免同时开两个游戏
6. **逐游戏适配层**（`adapters/`）：把各工具的命令行/配置差异封装起来，统一成"启动→等待→收尾"

## 📁 目录结构

```
hoyo-daily-3in1/
├─ auto_daily.py                  # 总控：顺序调度三个游戏
├─ display_mode.py                # 屏幕模式快照/切换/还原（窗口化 ↔ 你的全屏）
├─ web_config.py                  # 本地配置面板（http://127.0.0.1:89xx）
├─ start_page.bat                 # 一键启动配置面板
├─ adapters/
│  ├─ bettergi.py                 # 原神：生成一条龙配置并启动 BetterGI
│  ├─ starrail.py                 # 崩铁：写 March7th 配置并启动完整运行
│  └─ zzz.py                      # 绝区零：启动 OneDragon CLI（一条龙）
└─ config/daily_config.example.yaml   # 复制为 daily_config.yaml 后修改
```

## 🚀 安装（三步）

1. **准备三个上游工具**（从各自 GitHub Releases 下载，放到 `tools/` 与 `OneDragon-ref/`）：
   - BetterGI → `tools/BetterGI/BetterGI/BetterGI.exe`
   - March7thAssistant → `tools/March7thAssistant/March7th Assistant.exe`
   - ZenlessZoneZero-OneDragon → `OneDragon-ref/`（源码 + `uv sync` 建环境；或用官方打包版）
   - 路径不同也没关系：设置环境变量 `HOYO_BETTERGI_DIR` / `HOYO_MARCH7TH_DIR` / `HOYO_ONEDRAGON_DIR` 覆盖
2. **本项目的 Python 环境**：`python -m venv .venv && .venv/Scripts/pip install -r requirements.txt`
3. **配置**：复制 `config/daily_config.example.yaml` → `config/daily_config.yaml`，填你自己的游戏路径与目标；再双击 `start_page.bat` 打开面板核对，并点「保存定时」注册 7:30 计划任务（首次需管理员）

## 🕗 每日流程

```
07:30（计划任务，最高权限，无 UAC）
  └─ auto_daily.py
       ├─ 原神：切 1920×1080 → BetterGI 一条龙（清树脂/秘境/领奖）→ 关游戏 → 还原全屏
       ├─ 崩铁：切窗口 → March7th 完整运行（清体力）→ 关游戏 → 还原全屏
       └─ 绝区零：切窗口 → OneDragon 一条龙（签到/邮件/电量/驱动盘）→ 关游戏 → 还原全屏
日志：logs/daily.log（每个游戏都有「执行结束 ok=True / 已恢复用户原屏幕模式」）
```

## 🧭 踩坑记录（真金白银，欢迎抄作业）

1. **绝区零 OneDragon 必须以管理员运行**：否则它对受保护的游戏窗口发 PostMessage 会被系统拒绝（错误码 5），表现就是"鼠标在动但游戏毫无反应"。
2. **"窗口存在就跳过登录"死区**：OneDragon 检测到游戏窗口存在就跳过「打开并登录游戏」；若游戏停在登录页，整个流程会在登录页反复空转。调度层应先关闭游戏，让它走完整的打开+登录流程。
3. **计划任务 = 零 UAC 的关键**：任务用 `/RL HIGHEST` 注册后，其子进程天然提权——适配器里判断"已是管理员就直接启动、否则才 runas"，手动运行时才需要点一次确认。
4. **大日志别整读**：等待引擎完成时如果每次都把日志整文件读进内存，会拖死主流程；改为只读文件尾部（tail N KB）。
5. **双重等待会误判**：启动阶段等过一遍、收尾又等一遍，第二次会看到"进程早已退出"而误报失败——等待接口要有"已完成"短路。
6. **不同显示缩放下 DPI 感知**：150% 缩放环境下，未声明 DPI 感知的进程读到的窗口尺寸是虚拟化的（1920×1080 被读成 1280×720），截图/点击坐标会整体错位。
7. **开机自启与补跑**：`Interactive` 登录型任务 + "错过计划后尽快启动"，可以做到"7:00 开机、7:30 自动跑；若错过，登录后补跑"。
